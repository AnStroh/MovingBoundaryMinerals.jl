MovingBoundaryMinerals.jl

MovingBoundaryMinerals.jl is a software package for modelling diffusion-controlled growth and resorption processes in mineral/mineral or mineral/matrix pairs. It can either calculate diffusion-limited growth or resorption for a prescribed rate, or solve the chemical Stefan problem, where the rate emerges from the solution instead of being prescribed. See General Remarks for an overview, Configuration Options for the switches that control which code path is used, Numerical Approach for the numerical scheme, Boundary Conditions for the equations at the domain edges and the interface, Mesh Refinement for how the grid is regenerated as the interface moves, and Chemical Stefan Problem for the thermodynamic constraint.

For further details, we recommend reading [1].

Installation

MovingBoundaryMinerals.jl requires Julia 1.10 or later (tested on the latest LTS release and 1.11, on Linux, Windows, and macOS (Apple Silicon) — see the CI workflow for the exact matrix). It is a registered package and can be added as follows:

using Pkg; Pkg.add("MovingBoundaryMinerals")

or

julia> ]

(@v1.10) pkg> add MovingBoundaryMinerals
Install from a specific branch

As the API is changing and not every new feature leads to a new release, one can also clone the main branch of the repository directly:

add MovingBoundaryMinerals#main

After installation, you can test the package by running the following commands:

using MovingBoundaryMinerals

julia> ]

(@v1.10) pkg> test MovingBoundaryMinerals

The test suite can take a while to run.
